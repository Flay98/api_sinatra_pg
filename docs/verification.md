## Автоматические тесты

Команда: `bundle exec rake test`.

```text
Run options: --seed 56035
57 runs, 595 assertions, 0 failures, 0 errors, 0 skips
```

Проверены модели, ассоциации в обе стороны, scopes, типы и значения по умолчанию,
timestamps, сериализация списков и записей, CRUD всех ресурсов, различие PUT/PATCH,
фильтры по отдельности и в сочетании, подстрочный поиск, символы SQL/regex,
JSON/form/query-запросы, ошибки 400/404/409/415/422, HEAD/OPTIONS,
маршруты части 2, загрузка `config.ru`, ограничения PostgreSQL,
обратимость миграций, восстановление seed-журнала после rollback,
идемпотентность и явная перезагрузка seeds, сброс ID, изоляция окружений и отказ
`db:reset` без точного подтверждения имени БД.

В verbose-режиме Ruby показывает предупреждение об unused variable внутри
стороннего gem `sequel-seed` 1.1.2; оно не влияет на выполнение тестов.
Исходники стороннего gem не изменялись.
